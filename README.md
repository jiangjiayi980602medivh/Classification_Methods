# Classification Methods

In this project, we will talk about different ways of separate different dataset into different types according different data features.

In the PCA versus supervised separation, I will simulate a dataset with n = 200, d = 10, a = 2, and v = 300, drawing exactly 100 independent
observations from each class-conditional distribution. Reuse this dataset for 20 randomly generated stratified 70/30 splits: split each class separately into 70 training and 30 test observations.

Then I classified the simulated dataset into two types and compare the difference of mean and standard deviation. And also draw a scatterplot.
